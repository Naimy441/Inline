## 1. Cold open  `0:00 - 0:20`

**On screen:** A code editor where an agent edits a Markdown file, then a document page the agent cannot reach.

> AI agents have become remarkable writing partners. In a code editor, they read a whole project, make precise edits, and check their own work. But most of the writing that matters doesn't live in a code editor. It lives on the page.

## 2. Title  `0:20 - 0:26`

**On screen:** Inline mark and wordmark. "Real documents, with Claude Code and Codex built in."

> This is Inline.

## 3. The idea  `0:26 - 0:48`

**On screen:** You, the page and the agent; document tools flow between them; an edit arrives as a tracked change.

> Inline is a paginated document editor with Claude Code and Codex built in. The agent works on the same page you do, through more than forty document tools. And every edit it makes is a suggestion you can review. It's free, and open source.

## 4. Desktop app  `0:48 - 1:00`

**On screen:** The Inline desktop app opens on macOS; Mac, Windows and Linux badges.

> It runs as a desktop app on Mac, Windows, and Linux, with everything included. Let's open a real account.

## 5. Home  `1:00 - 1:22`

**On screen:** Home: color-coded folders with page previews, templates, folder view, search for "launch".

> This is home. Documents live in color-coded folders, with live previews of their pages. Templates cover essays, MLA papers, reports, résumés and more. And search finds any document in a keystroke.

## 6. The editor  `1:22 - 1:44`

**On screen:** The thesis proposal scrolls: title, live table of contents, citations, equation, table, figure, headers and page numbers.

> Open a thesis proposal and you get real pages. A live table of contents, citations, LaTeX equations, tables and figures, with headers and page numbers. Everything you'd expect from a word processor.

## 7. Claude in the document  `1:44 - 2:18`

**On screen:** Command J opens Claude. "Tighten the introduction." Tracked changes appear on the page; Keep all.

> Press Command J, and Claude joins you. Ask it to tighten the introduction. Claude reads the document and edits the page directly. Every change appears as a tracked suggestion: deletions struck through, additions highlighted. It even noticed a citation that doesn't match its source. Keep what you like and undo the rest, one change at a time, or all at once.

## 8. Ask about a selection  `2:18 - 2:40`

**On screen:** A paragraph is selected, Command L adds it to the chat, Claude checks the source and rewrites the sentence.

> Select a passage and press Command L to ask about just that part. Here, Claude checks the claim against the paper, finds the right hurricane, and rewrites the sentence, with its sources.

## 9. Comments  `2:40 - 3:00`

**On screen:** The advisor's three comments; Claude addresses them, replies in each thread and resolves it.

> Comments work the way you'd expect. My advisor left three. Ask Claude to address them, and it fixes each one in the text, replies in the thread, and resolves it.

## 10. Versions  `3:00 - 3:14`

**On screen:** Version history: a named version is saved, then the first draft opens for comparison.

> Save named versions as you go, and open any earlier draft to compare it or restore it. Every reply from the agent leaves a restore checkpoint, too.

## 11. Claude or Codex  `3:14 - 3:27`

**On screen:** The model menu: provider Claude or Codex, and every model; switching to Codex.

> Prefer Codex? Switch providers or models in the middle of a conversation. The next model picks up the same transcript, and the same document.

## 12. Canvas  `3:27 - 3:44`

**On screen:** A designed field guide Canvas: cover, three columns, an equation box and a table; a heading is edited by hand.

> When the layout is part of the message, use a Canvas. The agent designs editable pages with columns, color, and type, and you can still click in and change any word.

## 13. PDF import  `3:44 - 4:07`

**On screen:** A lecture PDF is imported; the conversion runs in the chat; original and rebuilt page side by side.

> Import a PDF, and Inline matches its page size, fonts, and margins. Then Claude rebuilds each page as editable text, with equations in LaTeX, and checks its work against the original, side by side.

## 14. Organize with AI  `4:07 - 4:22`

**On screen:** Eight unfiled documents; Organize with AI files them into the four folders.

> Back home, Organize with AI files everything into folders in seconds. It reads only titles and first lines, so it barely touches your usage.

## 15. Your files  `4:22 - 4:40`

**On screen:** A Finder window of the Word copies in Documents/Inline; export formats; Google Docs import.

> Your documents stay yours. Inline keeps a Word copy of every one in a folder on your computer, exports to PDF, Markdown and more, and brings in your whole Google Drive from a single zip.

## 16. Claude Code over MCP  `4:40 - 4:59`

**On screen:** A terminal running Claude Code with the Inline MCP server beside the app; the edit lands live.

> And because Inline speaks MCP, Claude Code in your terminal can work on your documents too. Ask from the command line, and watch the edit land on the page.
